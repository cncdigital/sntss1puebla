# Project instructions

Before changing this repository, read [CHATGPT-INSTRUCCIONES.md](./CHATGPT-INSTRUCCIONES.md) completely.

The non-negotiable rules are:

- Work from the current `main`; synchronize before editing.
- Preserve existing changes and the backup `backup/reto-sindical-2026-09-24`.
- Never expose or invent credentials, PINs, tokens, cookies or personal data.
- Create/confirm a backup before authentication, database, role, PWA or Worker changes.
- Make minimal diffs and run the build and relevant tests.
- Never claim a deployment unless it was actually confirmed and verified.
- Do not change users, roles, database records or production environment variables without explicit authorization.
