# Espejo seguro del repositorio interno de Sites

Fuente oficial de producción: repositorio interno de Sites del proyecto SNTSS Sección I Puebla.
Commit de la fuente sincronizada: f9a40d5abe842063f3a2e232044e8d6132b55dce
Sitio publicado: https://sntss1puebla.com
Versión de Sites: 347

Este repositorio público existe para revisión y colaboración con Claude. La publicación se realiza desde Sites, no desde GitHub.

Se sincronizó el código textual de la aplicación, Worker, scripts, Android Auto/CarPlay y configuración necesaria para revisión. Se excluyeron deliberadamente:
- secretos, certificados, contraseñas y variables privadas;
- bases de datos, archivos de audio, imágenes privadas y datos personales;
- archivos generados con directorios o conocimiento que puedan contener información identificable;
- migraciones y pruebas con identificadores reales o datos de ejemplo sensibles.

Antes de proponer cambios de seguridad, autenticación, datos personales o producción, usa el repositorio interno de Sites como fuente de verdad y conserva la copia de respaldo.
